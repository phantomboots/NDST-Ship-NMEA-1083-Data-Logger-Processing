**NDST Ship NMEA-0183 Data Logger Processing.R**

This R scripts is designed to read in a series of .txt log files generated by the program Advanced Serial Data Logger, on a standalone PC (as of 2025, the NDST Kinupute PC). The log files are generated from a serial connection between the ship's GPS data feed and 
the serial port on the standalone PC. All available NMEA-0183 data setences available from the ship's NMEA-0183 output source are logged, but the script focuses on extracting the $GPGGA, $GPZDA and $GPRMC data sentences.

All log files are concatenated into a master record, and then filtered to only  $GPGGA, $GPZDA and $GPRMC data sentences. The UTC time is then extracted from the ZDA sentence, and appended to the data records for the $GPGGA and $GPRMC sentences.

The timestamped data are then converted to a geographic coordinates (decimal degrees) and all columns except UTM date, time and lat/long are dropped. 

The resulting data is written to a .CSV as well as a .SHP file, with point type geometry.
